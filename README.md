## 🌟 Overview

**Skillence Academy** is a modern, high-performance, single-page web platform designed for hands-on computer education. The website combines cinematic visual design, interactive 3D frame scroll animations, and a seamless course inquiry experience.

---

## ✨ Features

- **Interactive 3D Scroll Animation**: Canvas-driven high-DPI scroll sequence synchronized with viewport scrolling.
- **Brand Landscape Identity**: Integrated transparent vector-grade brand mark across navbar, preloader, and footer.
- **Course Catalog with Live Software Showcases**:
  - ADCA+ with AI (MS Office, Canva, ChatGPT, Prompt Engineering)
  - Tally with GST (Billing, Multi-tier Tax, Voucher Accounting)
  - Advance Video Editing (Premiere Pro, After Effects, Motion Graphics)
  - CSC Advance (Digital Government Services, Online Operations)
- **Lead Generation Modal**: Interactive counseling booking form with client-side validation, error handling, and server storage.
- **Dual Interactive Carousels**: Touch-friendly, draggable carousels for core software and AI productivity tools.
- **100% Mobile Responsive**: Optimized for all viewports from 360px mobile devices to 4K displays.
- **Fast Local Server**: Lightweight PowerShell HTTP server with built-in `/api/leads` REST endpoint.

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Edge, Firefox, Safari)
- Windows PowerShell (for local server) or any static web server

### Running Locally
To launch the website with full lead form API support:

```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Or simply double-click:
```bat
start-server.bat
```
Then open your browser at:
```
http://localhost:8080/
```
